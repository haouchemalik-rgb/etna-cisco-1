# Réseaux Cisco — configuration progressive d'une topologie (Packet Tracer)

> Projet ETNA — module Réseaux Cisco, niveau 1 · Mars – avril 2024

Construction pas à pas d'une topologie réseau sous **Cisco Packet Tracer** : chaque fichier correspond à l'état du réseau à la fin d'une étape, ce qui permet de suivre la progression de la configuration.

**Compétences mises en œuvre :** Cisco IOS · configuration de routeurs et de switchs · adressage IP · sécurisation de base des équipements (nommage, mots de passe d'accès)

## Contenu

| Fichier | Contenu |
|---|---|
| `etape1.pkt` → `etape6.pkt` | Topologie à la fin de chaque étape du sujet |
| `bonus.pkt` | Étape bonus |

Les équipements sont nommés et protégés par mot de passe (console / mode privilégié) dans les étapes finales.

## Ouvrir les fichiers

Installer [Cisco Packet Tracer](https://www.netacad.com/cisco-packet-tracer) (gratuit avec un compte Cisco NetAcad), puis ouvrir le fichier `.pkt` de l'étape souhaitée.
